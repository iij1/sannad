**Sanaad Pro Analytics** هو تطبيق ويب تحليلي متقدم مصمم لتحليل مخاطر إصابات اللاعبين الرياضيين بناءً على بيانات الأداء والإحصائيات الجسدية. يوفر واجهة رسمية وبسيطة مع تصورات بصرية دقيقة باستخدام Streamlit وPlotly.

## المميزات
- **تحليل مخاطر الإصابة**: يقيّم مخاطر الإصابة بناءً على معايير مثل الإجهاد، معدل النبض، التدخلات، والترطيب.
- **خريطة ملعب تفاعلية**: تعرض مواقع اللاعبين مع تفاصيل الأداء عند التمرير.
- **لوحة أداء اللاعب**: تتيح تحليل أداء اللاعب الفردي مقارنة بمتوسط الفريق.
- **تصميم رسمي**: واجهة نظيفة بألوان هادئة واحترافية.

## المتطلبات
- Python 3.8 أو أحدث
- المكتبات المدرجة في `requirements.txt`
